焼印
Interface

会計の最後に、整理番号を豆腐へ「焼印」として押す。炭火の店の動作そのものを、レジの操作体系にする提案です。

Concept / System / Screens / Interaction / Build
01 — Concept

網・空白・焼印。

網

Grill Grid

焼き網の棒を、そのまま画面の罫線にする。選択肢はすべて網の上に並ぶ横一列の「レール」。迷う余地をなくす。

□

White Void

ポスター中央の白い四角＝豆腐。画面で唯一の白い面に「お釣り」だけを置く。会計中に見るべき数字は、いつもここ。

印

Yakiin

白い豆腐を長押しで「焼く」。網目の焦げ跡が走り切ったら会計確定、整理番号が焼印として押される。誤タップでは確定しない。

整理番号 ／ TICKET
  • 本数：巨大な数字を上下に撫でると増減（＋/−も残す）。
  • 客層：網の棒＝3本のレール。押すと白く焼ける。任意。
  • 受け取った額：未選択のあいだ、白い四角は消灯（焦げ色）して押せない。
  • 購入：白い四角を0.6秒長押し。網目の焦げが左から走り切ったら確定。指を離せば取り消し。
  • 直後：画面全体が炭色になり、整理番号を焼印で押す。1.6秒で次の客へ。タップで即戻る。

05 — Interaction Spec

動きの約束。

CONFIRM長押し600ms。離せば中断。触覚フィードバック1回。二重確定は会計IDで防止（既存）。
BRAND焼印の押下は450ms、全体1.6秒。表示中も次の操作でスキップ可能。会計の保存は押下前に完了。
SWIPE本数ゾーンで縦に24pxごとに±1。横スワイプは無効（誤操作防止）。
REDUCED「動きを減らす」設定では焦げ・焼印の動きを省き、整理番号を静止表示。
CONTRAST炭色背景上の文字は#F3EDE6（コントラスト比 15:1 以上）。白い四角の中は炭色の文字。
06 — Build

今の機能のまま、皮を替える。

データ・同期・客層・整理番号・受け取った額の規則は現行のまま。変わるのはレジ画面の構成と、長押し確定・焼印演出・ゴマ・ログの3つ。Android（Compose）とiOS（SwiftUI）の標準APIだけで実装でき、新しい依存は不要。

Phase 1

配色・罫線・数字の組版・長押し確定。

Phase 2

焼印演出・触覚・動きを減らす設定への対応。

Phase 3

履歴のゴマ・ログ、締めの網グラフ。
